# Grade Reporter & Bug Hunt

This repository contains my PLP Python Week 3 assignment.

- `grade_reporter.py` - Uses a for loop, conditions, counters, and calculations to report grades, passes, failures, and the average score.
- `bug_hunt.py` - Fixes three bugs in a while loop program that calculates the sum of numbers from 1 to 5.

The hardest bug to find was the while-loop condition because it did not produce an error message. The program could run normally but give the wrong answer because `count < 5` stopped the loop before adding 5. I knew something was wrong because the program printed a result different from the expected answer of 15.
